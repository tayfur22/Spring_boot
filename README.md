# Spring Boot - Java Backend Demo Project

This is a simple backend project developed using Java Spring Boot framework. It serves as a demo for basic API development and Spring Boot project setup.

---

## Features:
- RESTful API endpoints
- Basic CRUD operations
- Maven-based project setup
- Spring Boot auto-configuration

---

## Technologies Used:
- Java 23
- Spring Boot
- Maven
